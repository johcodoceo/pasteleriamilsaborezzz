## Preparar la explicación y entrega

La rúbrica asigna 40% al encargo y 60% a la explicación individual. Antes de grabar, cada integrante debe poder localizar y explicar un ejemplo real de HTML semántico, CSS externo, validación JavaScript y persistencia del carrito, junto con sus aportes al repositorio.

Propuesta de recorrido para el video de 5 a 8 minutos sugerido por la pauta:

1. Presentar integrantes, sección, grupo y caso Forma C.
2. Recorrer Inicio, Productos y un detalle; explicar brevemente la estructura HTML y los estilos compartidos.
3. Agregar productos al carrito, modificar o eliminar una selección y recargar para demostrar localStorage.
4. Mostrar un formulario incorrecto, explicar la regla JavaScript y corregir los datos para completar la operación.
5. Mostrar una vista administrativa y la consulta de órdenes del Vendedor.
6. Abrir el GitHub real del grupo y explicar commits y aportes identificables. Todos los integrantes deben participar.

La grabación debe mostrar la misma versión que contiene GitHub. Subir el video a Google Drive, comprobar reproducción y descarga y conservarlo fuera del repositorio. Los commits deben reflejar trabajo real, sin atribuir cambios automáticamente a un estudiante.
